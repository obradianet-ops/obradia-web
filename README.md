# obradia.net

Web informativa de Obradia, publicada con GitHub Pages en https://obradia.net. El botón «Acceder al portal» lleva a la aplicación en https://app.obradia.net.

HTML y CSS estáticos, sin dependencias ni analítica. Las fuentes (Inter y Lora, licencia OFL) se sirven desde `fuentes/`.

Para verla en local: `python3 -m http.server` en esta carpeta.
